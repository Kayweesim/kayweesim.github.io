Story Studio

A personal video studio for one YouTube channel.

What it is

Story Studio is a private tool that runs on my own computer. I use it to put together short vertical videos (YouTube Shorts) for my own channel: collecting clips, organising them into rankings, and keeping track of the finished videos.

How it uses YouTube

When a video is finished, Story Studio can upload it to my YouTube channel using the YouTube Data API. Every upload needs my manual approval first, and I check the title, description and tags before anything is sent. The tool only ever uploads to the channel I sign in with.

  • It uploads videos I have made and approved (YouTube Data API videos.insert).
  • It reads my channel's name and the status of videos it uploaded, so it can show whether each upload finished.
  • It does not read, change or delete any other videos, comments, subscribers or analytics.

Who can use it

Story Studio is not a public service and has no other users. It is not offered, sold or shared with anyone else.
